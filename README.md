# ElGatoDosJugadores
Desarrollado por:
- Adalberto Ruiz Chavez

Este proyecto consiste en un juego de El Gato (Tic-Tac-Toe) para dos jugadores utilizando una arquitectura cliente-servidor.
Los dos jugadores se conectan al mismo servidor mediante un puerto de comunicación. Cada jugador cuenta con una interfaz gráfica desarrollada en Java Swing, donde puede realizar sus movimientos y visualizar los movimientos realizados por el otro jugador.

El proyecto permite practicar conceptos de programación en red, comunicación mediante sockets y desarrollo de interfaces gráficas.

Características principales:
- Juego de El Gato para dos jugadores.
- Arquitectura cliente-servidor.
- Comunicación mediante sockets.
- Interfaz gráfica con Java Swing.
- Sincronización de movimientos entre jugadores.
- Visualización de los movimientos realizados por ambos jugadores.
- Sistema de turnos.

Tecnologías utilizadas
- Java
- Java Swing
- Sockets TCP
- Arquitectura cliente-servidor

Importante
-
El servidor debe estar ejecutándose antes de iniciar las conexiones de los jugadores. Ambos clientes deben utilizar la misma dirección IP y puerto configurados en el servidor.
